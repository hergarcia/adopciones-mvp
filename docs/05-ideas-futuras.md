# 05 — Ideas futuras (congeladas)

Todas dependen de que la adopción funcione primero. La identidad verificada es la infraestructura
común que las hace posibles.

## Perdidos y encontrados
- Urgencia + geolocalización + viralidad.
- Facebook es brutalmente bueno en esto; difícil ganarle.
- Posible ángulo: cruzar con RENAC/chip para reunificación verificada.

## Donaciones para tratamientos
- Manejo de dinero: regulación, responsabilidad.
- Es el vector de estafa número uno del rubro (fotos robadas de animales enfermos).
- Si se hace: solo con rescatistas nivel 2+ con historial, y con comprobantes veterinarios.

## Cat/Dog sitters
- Es Rover. Pagos, seguros, disputas, confianza física en casa ajena.
- La verificación de personas es la base natural; es la vertical más monetizable.

## Otras que aparecieron
- Traspaso de titularidad del chip (RENAC) integrado al cierre de adopción. **Esta sí podría entrar
  temprano** si el trámite lo permite: es diferencial local y alineado con INBA.
- Tarifa simbólica anti-spam para particulares (modelo Rehome).
- Integración con software de refugios (si alguna vez existe algo así en Uruguay).
- Alianzas con veterinarias/petshops (descuentos para adoptantes verificados).
