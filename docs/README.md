## Convenciones

- Español rioplatense.
- Cada decisión tomada va en negrita con fecha: **Decisión (2026-09-16):** ...
- Las ideas que se descartan no se borran, se mueven a una sección "Descartado" con el motivo.
- **Siempre últimas versiones** de paquetes, APIs e integraciones. Es un MUST. Verificar antes de
  instalar; nunca fijar a un major viejo. Detalle en `07-stack.md`, sección "Versiones".
